# Instructions

1. Install the game
2. Run the game and play for a bit (recommended: skip the tutorial and play at least 2 levels)
3. Move the telemetry file stored in "TimelessDeck_UAJ\Game\telemetry" to "analytics\telemetry_data"
4. Open and run "analytics/analytics.py"
	- Information about the metrics will be displayed on console
	- Various graphics with the metrics information extracted from the telemetry data will be storage in a new folder inside analytics/results called Graphics_{timeStamp of the execution}
